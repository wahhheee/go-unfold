## 质量门槛

- 核验基线 Go 1.27.1 / linux / amd64；依赖扩展库时固定模块版本并记录其契约。
- 每节通过格式、类型、单测、生产构建、Go 测试与竞态检查；新增同步代码执行 vet。
- 每节通过桌面、手机、明暗主题、正文练习与实验流程检查，人工查看截图。
- 浏览器交互是明确限定的教学模型，真实调度、同步保证与故障验证由 `examples/go/` 补充；不得用某次输出证明全部可能执行。
- 每节通过检查后独立提交，使用 Conventional Commits 和简体中文。
- 完成全部十一节后审计规划覆盖、导航、练习归属和维护文档，再提交整章验收记录并停止。
