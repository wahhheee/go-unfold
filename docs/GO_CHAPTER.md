## 质量门槛

- 语言保证引用规范；实现细节注明 Go 版本及必要的平台前提。
- 当前核验基线为 Go 1.27，实际执行环境为 Go 1.27.1 / linux / amd64。
- Go 示例在 `examples/go/` 运行验证，前端实验模型独立测试。
- 每节发布前通过格式、类型、模型、Go 示例、构建和浏览器检查，并查看桌面与手机截图。
- 每完成一节单独提交，提交采用 Conventional Commits + 简体中文。
- 本章完成后做覆盖审计，更新序章与项目说明中的发布状态，再停止工作并汇报。
