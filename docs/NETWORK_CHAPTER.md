## 每节质量门槛

- 用具体场景引出机制，正文分成短段，四道预测题随讲随练；每个选项给出原因，另有四组连续追问与记忆锚点。
- 至少一个可操作的可视化实验。模型规则位于 `src/lib/`，输入改变后重置旧结果，支持重置或单步，并声明省略条件。颜色之外也用文字标注状态。
- 一手资料与核验日期进入每节元信息。协议规范、Linux 实现、Go API 与工程建议分开陈述；TCP 模型不假装实现完整拥塞算法。
- Go 固定样本位于 `examples/go/`；真实网络限于回环地址，测试显式限时并回收资源，不依赖外网、特权、固定端口或 Sleep 猜测顺序。
- 每节执行格式检查、类型检查、单元测试、生产构建、全量浏览器回归、Go 测试、vet 与 race。桌面、手机、明暗主题及无障碍流程均检查，人工查看截图后独立提交。
- 最后审计五组规划主题、首尾导航、搜索、练习归属、笔记与部署入口；仅全部完成后标记整章发布。

2026-09-20 完成十节：40 道随堂练习、40 组连续追问、10 个可操作实验、10 组真实 Go 验证。每节有固定核验日期、适用前提、选项解释与实验边界；短段讲解、预测题、操作与追问交替出现。上表保留各节独立提交时的检查快照。

课程地图的五组主题全部有实际正文：

| 规划主题                   | 对应课节与证据                                                            |
| -------------------------- | ------------------------------------------------------------------------- |
| TCP、拥塞控制与连接管理    | 3.2 字节流、半关闭与状态；3.3 累计确认、窗口、重传、经典算法与 BDP        |
| HTTP/1.1、HTTP/2 与 HTTP/3 | 3.4 语义与消息边界；3.5 流、TCP 队头阻塞、QUIC 与 QPACK 的依赖边界        |
| TLS、DNS 与连接池          | 3.1 缓存与连接两种生命周期；3.4 Body 与池；3.6 身份、握手、恢复与早期数据 |
| 进程、线程与虚拟内存       | 3.7 资源与执行、fd 引用和共享偏移；3.8 映射、缺页、COW 与内存口径         |
| I/O 多路复用与 Go netpoll  | 3.9 就绪、读取、LT/ET 与 G 的等待；3.10 分段观测、预算、结果未知和退出    |

重点保留几个容易被口号掩盖的事实：TTL 不迁移现有连接；TCP Write 与 ACK 不证明业务完成；HTTP Body 关闭与复用有版本和状态条件；HTTP/3 仍有共享资源及压缩依赖；TLS 加密不替代身份和授权；RSS 不是 Go heap；就绪不等于完整读取；取消不撤销远端提交；停止监听不等于活跃任务已经退出。

Go 基线为 1.27.1 / linux / amd64。Go 1.27.1 的有限 Body 排空通过源码和实测核验；TLS 1.3 引用 2026 年 7 月取代 RFC 8446 的 RFC 9846，HTTP 乐观协议切换另参考 RFC 9931。Linux 专用样本与 Go 公开契约分开说明，协议模型不冒充真实 QUIC、拥塞压测或 RSS 测量。
