# 第三章：网络与操作系统

## 交付安排

## 每节质量门槛

- 用具体场景引出机制，正文分成短段，四道预测题随讲随练；每个选项给出原因，另有四组连续追问与记忆锚点。
- 至少一个可操作的可视化实验。模型规则位于 `src/lib/`，输入改变后重置旧结果，支持重置或单步，并声明省略条件。颜色之外也用文字标注状态。
- 一手资料与核验日期进入每节元信息。协议规范、Linux 实现、Go API 与工程建议分开陈述；TCP 模型不假装实现完整拥塞算法。
- Go 固定样本位于 `examples/go/`；真实网络限于回环地址，测试显式限时并回收资源，不依赖外网、特权、固定端口或 Sleep 猜测顺序。
- 每节执行格式检查、类型检查、单元测试、生产构建、全量浏览器回归、Go 测试、vet 与 race。桌面、手机、明暗主题及无障碍流程均检查，人工查看截图后独立提交。
- 最后审计五组规划主题、首尾导航、搜索、练习归属、笔记与部署入口；仅全部完成后标记整章发布。
